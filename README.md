## 송인혁의 포스터 홀 둘러보기

### Background

**학회 발표**는 듣는 청중이 몇 초 안에 연구의 핵심을 파악할 수 있도록 구성되어야 합니다. 즉, 복잡한 연구 내용도 **한눈에 이해할 수 있도록 정리하고 전달하는 것**이 중요합니다.

저의 웹사이트 포트폴리오 역시 마찬가지라고 생각했습니다.

포트폴리오를 방문한 분들이 여러 프로젝트의 내용을 하나씩 찾아보지 않아도, **제가 어떤 문제를 고민했고 무엇을 만들어왔는지 한눈에 파악할 수 있는 방법**을 고민했습니다.

그러다 과거 **KCC 2025 학회**에 발표를 위해 방문했을 때의 풍경이 떠올랐습니다.
수많은 연구 포스터가 한 공간에 진열되어 있고, 관심 있는 연구를 자유롭게 둘러보던 **포스터 세션**의 모습이었습니다.

> **그렇다면 내 프로젝트도 학회 포스터처럼 한 공간에 전시해보면 어떨까?**

이 아이디어에서 시작해, 지금까지 진행한 프로젝트와 연구를 **하나의 학회 포스터 세션처럼 둘러볼 수 있는 공간**을 만들어보았습니다.
